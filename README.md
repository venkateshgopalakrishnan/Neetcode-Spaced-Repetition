# Neetcode Spaced Repetition 

A modern Chrome Extension (Manifest V3) designed to optimize your coding interview preparation by bringing Anki-style spaced repetition directly to [Neetcode.io](https://neetcode.io/). 

Instead of manually tracking which problems you need to review and when, this extension automatically detects when you successfully solve a problem and schedules it for review using the proven SuperMemo-2 (SM-2) algorithm.

## Key Features

- **Automated Detection:** Injects a lightweight content script that uses `MutationObserver` to silently detect when you pass all test cases on Neetcode, automatically adding the problem to your review queue.
- **SM-2 Algorithm Integration:** Implements the SuperMemo-2 spaced repetition algorithm. Rate your difficulty (Again, Hard, Good, Easy) and let the math determine your optimal review interval.
- **Cross-Device Syncing:** Built on `chrome.storage.sync`. To respect Chrome's strict 100KB sync quota, the extension uses a heavily compressed data schema (`interval|ease|repetitions|nextReview`), allowing you to flawlessly sync over 1,000 problems across multiple operating systems.
- **Premium UI Dashboard:** Features a beautiful, responsive popup built with React and Tailwind CSS to manage your daily "Due Today" queue and view your entire problem library.
- **Ollama hint coach:** Adds an AI hint panel directly to Neetcode problem pages. It reads the current editor, problem context, and language, streams hints from a local Ollama server, and keeps a separate hint history for each problem.

## Tech Stack

- **Framework:** React 19
- **Build Tool:** Vite + CRXJS (Hot Module Replacement for Extensions)
- **Styling:** Tailwind CSS v3 + Lucide React (Icons)
- **Language:** TypeScript (Strict typing for algorithms and Chrome APIs)
- **Extension API:** Chrome Manifest V3

## How It Works Under The Hood

1. **Content Script:** Runs silently on `*://*.neetcode.io/*`. When the "Accepted" DOM element renders, it extracts the problem slug and passes a message to the Background Service Worker.
2. **Background Worker:** Intercepts messages, checks `chrome.storage.sync` to prevent duplicates, and initializes the problem's metadata with an immediate due date.
3. **Popup Interface:** Reads the synchronized storage and calculates which problems are past their `nextReview` Unix timestamp, filtering them into the "Due Today" tab for the user to practice and re-rate.
4. **Hint Panel:** Sends browser requests to Ollama's `/api/chat` endpoint and streams the response into the injected panel.

## Installation & Local Development

Want to test it out or contribute? 

### 1. Install Dependencies
```bash
npm install
```

### 2. Build the Extension
For hot-reloading development:
```bash
npm run dev
```
For production build:
```bash
npm run build
```

### 3. Load into Chrome
1. Open Chrome and navigate to `chrome://extensions/`
2. Enable **"Developer mode"** in the top right corner.
3. Click **"Load unpacked"** and select the `/dist` directory generated by the build step.
4. Pin the extension to your toolbar, head over to Neetcode, and solve a problem!

### Ollama hint coaching

Install and run [Ollama](https://ollama.com/) locally, then pull a chat model:

```bash
ollama pull llama3.2
ollama serve
```

Because the extension runs in the browser, Ollama must allow the extension origin. Set `OLLAMA_ORIGINS` before starting Ollama (include the origin shown in the browser console if it differs):

```bash
OLLAMA_ORIGINS="chrome-extension://*,https://neetcode.io,https://*.neetcode.io" ollama serve
```

Use the injected panel's header to drag it out of the way of the Neetcode editor. Resize it from the lower-right corner, or use the collapse button for a compact header. The gear icon changes the endpoint, model, system prompt, or learner request. Both prompts have a **Restore default** control, and blank values cannot be saved. These settings, panel layout, and each problem's hint history are stored in Chrome local storage. Individual hints can be removed, or **Delete all** clears the current problem's history. Empty editor requests are blocked, and **Cancel** stops an in-progress stream. Network, HTTP, malformed-stream, and Ollama errors are shown in the panel.

---

*Note on the `key` in `manifest.config.ts`: There is a public RSA key hardcoded into the manifest. This is an intentional best-practice for unpacked extensions. It safely locks the Extension ID so that Chrome Sync works perfectly if you use this extension across multiple computers (e.g., Ubuntu and Windows) logged into the same Google Account. It poses zero security risk.*
